# Les raccourcis de Glucose — la couche de base du preset de Glucose (P4, fiche 72).
#
# Un accord, puis la commande qu'il désigne ; plusieurs, séparées par |, la première qui
# s'applique l'emportant ; - retire l'accord des couches du dessous. Les modificateurs : Ctrl,
# Alt, Maj. Un chiffre est la touche marquée de ce chiffre, quel que soit le clavier.
#
# Ce sont exactement les raccourcis du code d'avant la fiche 72 : rien n'a changé à l'écran.
